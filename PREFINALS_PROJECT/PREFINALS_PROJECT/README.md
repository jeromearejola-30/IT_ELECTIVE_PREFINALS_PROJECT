# Help Desk System (.NET 8 MVC)

An ASP.NET Core MVC application built using Entity Framework Core and an existing SQLite database (`lycevm.db`).

## Project Setup & Prerequisites
1. **Framework:** .NET 8 SDK
2. **Database:** SQLite (`lycevm.db` placed in the project root)
3. **NuGet Packages:**
   - `Microsoft.EntityFrameworkCore.Sqlite`
   - `Microsoft.EntityFrameworkCore.Design`
